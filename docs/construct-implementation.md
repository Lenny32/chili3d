# Construction ticket implementation record

This change implements the seven `tickets/construct-*` tickets using one persistent construction-node model. All 20 public creation tools share source capture, preview, property editing, history, and serialization. The [architecture](construct-architecture.md) records ownership, reference resolution, transforms, dependency ordering, and invalidation; the [user guide](construct-user-guide.md) describes the Construct ribbon and downstream sketch/revolve workflow.

| Ticket | Implemented behavior | Verification |
| --- | --- | --- |
| CONSTRUCT-01 foundation | Serializable plane, axis, point, and UCS nodes; strict references and visible invalid state; dependency notifications; selection, visibility, property editor, ribbon, sketch/revolve consumers, and datum-point snapping. | Construction lifecycle, resolver, consumer, renderer, and command tests; browser preview, create/edit/reopen, and sketch-from-plane smoke. |
| CONSTRUCT-02 basic planes | Offset (including To Object), midplane with stored bisector choice, and angle plane with baseline and optional offset. | Numerical evaluator tests for signed distances, degeneracy, axis containment, transformed sources, and definition round trips. |
| CONSTRUCT-03 reference/path planes | Two-edge, three-point, and along-path definitions; ordered connected chains, arc-length placement, path reversal, branch choice at corners, extension rules, and optional offset. | Core and real-kernel tests for intersections, curved arc length, disconnected chains, corners, and ambiguous projections. |
| CONSTRUCT-04 surface planes | Tangent and perpendicular plane definitions with face contact, local normals, orientation references, and offset. | Numerical and real-kernel surface tests, including invalid domains and singular/undefined normals. |
| CONSTRUCT-05 axes | Analytic symmetry, face normal, plane intersection, two-point, and straight-edge axes; construction-axis revolve input. | Numerical and kernel tests plus actual cached revolve edit/delete/undo dependency tests. |
| CONSTRUCT-06 points | Vertex/snap, two-edge, three-plane, analytic center, edge-plane, and along-path points; multiple-solution selection and point snapping. | Core and kernel tests for intersections, source edits, identity, arc length, and viewport picking. |
| CONSTRUCT-07 UCS | Editable right-handed frame; stable XY/YZ/ZX and X/Y/Z members; local/world conversions; working-plane activation and associated sketch creation. | Frame and conversion tests, node round trips, consumer tests, and command tests. |

Validation at the final integrated run: `npm run check`, `npx tsc --noEmit`, and the production build passed. The focused construction suites passed **114/114**. The full suite reported **6,477 passed, 1 failed**; the sole failing test was generated-capabilities freshness after a Windows generator/Biome subprocess `UV_HANDLE_CLOSING` error. An isolated rerun failed in the same subprocess, while the generated file itself matches the committed baseline. Browser smoke covered an offset-plane preview, cancellation, creation, edit and reopen, plus sketch creation from that plane without page errors; it did **not** manually exercise all 20 creation dialogs or direct datum-point picking. Datum-point snapping and renderer selection are covered by automated tests.

Reference identity has deliberate limits. Tracked topology IDs are used when available; selected untracked analytic faces/circles and box-corner vertices can follow dimensional edits when their semantic role is unique. Other untracked topology must retain its captured fingerprint and index, and invalidates rather than attaching to a nearby replacement. Curved edge intersections use the kernel when supported; unsupported curve pairs produce an explicit error. Path extension is defined for a single straight segment, while unsupported curved/chain extension is rejected. Equal-distance To Object projections and unspecified sharp-corner tangents are treated as ambiguous until a solution/branch is chosen.
