# Construction geometry

Open the **Construct** ribbon and choose a plane, axis, point, or UCS tool. Each tool opens a small editor. Select every named source, enter distances in millimetres or angles in degrees, and inspect the preview. **Create** adds a named document object; **Cancel** removes the preview without changing the document. Select a construction object in the tree and use **Edit Construction** to change its references and values. Rename, show or hide, delete, undo and redo work through the normal document controls. Display size changes the visual marker, not the infinite mathematical plane or axis.

The plane tools are **Offset**, **Midplane**, **At Angle**, **Through Two Edges**, **Through Three Points**, **Along Path**, **Tangent**, and **Perpendicular**. The axis tools derive a symmetry axis from a cylinder/cone/torus, a normal at a face point, an intersection of two planes, a line through two points, or the extension of a straight edge. The point tools derive a vertex/snap, two-edge intersection, three-plane intersection, circle/sphere/torus center, edge-plane intersection, or path position. A UCS uses an origin and two assigned directions; reverse either direction to choose another right-handed orientation.

Source pickers can use model faces, edges and vertices, existing construction objects, global origin planes, or explicit fixed coordinates. For a UCS source, select the desired XY/YZ/ZX plane or X/Y/Z axis. Path tools accept a position measured by length, a normalized fraction, or a point projected to the path. The path direction and branch controls preserve the chosen solution. The Point on Face mode stores the face and its surface parameters so contact follows edits. Invalid, ambiguous and missing sources show an error in the editor or on the tree row; repair the reference or undo the source change.

Select a construction plane and activate it to use it as the working plane. Select a UCS and activate one of its XY, YZ or ZX planes. The next sketch can retain that plane's identity and follow later edits. A construction axis can likewise be selected as the revolve axis; later axis edits update the feature. Existing global working-plane shortcuts remain available.
